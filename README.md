# MuMuRealRun - MuMu 安卓模拟器运动模拟器

[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/)
[![Platform](https://img.shields.io/badge/platform-Windows-brightgreen.svg)](https://windows.microsoft.com/)
[![MuMu Version](https://img.shields.io/badge/MuMu%20Player-12.0%2B-orange.svg)](https://mumu.163.com/)

**MuMuRealRun** 仿照 GitHub 著名开源项目 **`iosrealrun`** 的核心设计理念，为 **网易 MuMu 安卓模拟器（尤其是 MuMu 12）** 量身打造的一套高拟真、防作弊检测的运动轨迹与虚拟定位模拟系统。

项目彻底摆脱了本机硬编码路径的限制，采用多级智能探测引擎，可无缝移植至任意 Windows 设备，并提供一键启动脚本与直观美观的终端交互仪表盘。

---

## 🌟 核心特性与技术亮点

### 1. 模拟器底层硬件级注入（防封号/防作弊检测）
- 普通安卓虚拟定位软件通常需要开启系统开发者选项中的“允许模拟位置 (Mock Location)”，运动类 App（如咪咕跑、高校体育、阳光体育等）能轻易检测到该标志并判定作弊封号。
- **MuMuRealRun** 直接调用网易官方底层管理接口 `MuMuManager.exe control -v <index> tool location`，在模拟器虚拟化硬件层面注入 GPS 卫星信号。对于安卓系统和应用而言，该定位与真实手机 GPS 芯片硬件回报完全一致，隐蔽性极高。

### 2. 拟真人类跑步物理仿真（对标 `iosrealrun`）
- **平滑自然速度波动**：采用奥恩斯坦-乌伦贝克 (Ornstein-Uhlenbeck) 惯性随机游走算法，使跑步速度在设定基准（如 3.2 m/s）上下 ±10% 范围内自然起伏，杜绝机械式恒速。
- **卫星多径漂移 (GPS Jitter)**：模拟真实手机在户外接收卫星信号时的微弱横向扰动（±0.5m~1.2m），避免轨迹点落在绝对笔直的几何折线上。
- **弯道拟真减速**：智能检测路线转弯角度，在大角度弯道处自然减速 15%~25%，出弯后平稳加速回弹。
- **步频与步数估算**：实时根据瞬时配速拟合步幅（约 165~185 spm），实时显示估算步数。

### 3. 高精度国内坐标系自动纠偏转换
- 国内主流地图（高德开放平台、腾讯地图等）提取的路线坐标均为 **GCJ-02 (火星坐标系)**。
- 安卓底层 GPS 驱动以国际标准 **WGS-84** 运行。若将 GCJ-02 坐标未经转换直接喂给模拟器，应用内的高德地图 SDK 会对其进行二次纠偏，导致轨迹整体向外偏移数百米！
- 本项目内置毫米级迭代坐标转换算法，在将坐标送入模拟器底层前自动将其从 `GCJ-02` 换算为 `WGS-84`，使运动 App 在地图上还原时恰好完美贴合真实跑道。

### 4. 完全与本机解耦（零硬编码，一键部署）
- **多级自适应探测链**：
  1. 探测系统环境变量 `MUMU_DIR` / `MUMU_PATH`；
  2. 探测 Windows 运行中进程（`MuMuNxMain.exe` 等可执行文件绝对路径）；
  3. 检索 Windows 注册表（`Uninstall` 项中的安装路径）；
  4. 扫描常见磁盘安装目录；
  5. 自动寻找配套的 `adb.exe` 调试桥。
- 在任何新电脑上解压即可使用，无需手动修改代码中的安装路径。

### 5. 交互式终端仪表盘 (Terminal Dashboard)
- 集成实时配速、瞬时时速、平均配速、已跑距离、目标进度条、预估剩余时间 (ETA) 与圈数统计。
- 支持实时键盘热键交互：
  - **`[空格 / P]`**：暂停 / 继续跑步
  - **`[+]`**：即时提速 (+0.2 m/s)
  - **`[-]`**：即时降速 (-0.2 m/s)
  - **`[Q / Ctrl+C]`**：安全退出并生成本次跑步结算清单

## 🚀 快速上手与部署

### 环境要求
- 操作系统：Windows 10 / 11 (64位)
- 模拟器：[MuMu 模拟器 12](https://mumu.163.com/)
- Python：Python 3.8 及以上版本

### 方式一：一键双击运行（推荐）
直接双击项目根目录下的 **`start.bat`**：
1. 脚本将自动检查 Python 环境与依赖包（缺失时自动通过国内镜像安装）；
2. 弹出交互菜单，可选择直接开跑、运行环境自检或输入目标公里数。

*(PowerShell 用户可直接执行 `.\run.ps1`)*

---

### 方式二：命令行手动运行

1. **安装依赖**：
   ```bash
   pip install -r requirements.txt
   # 或使用 uv:
   uv pip install -r requirements.txt
   ```

2. **环境自检 (Doctor)**：
   ```bash
   python main.py --doctor
   ```
   *该命令会自动扫描本地 MuMu 模拟器、检测 `MuMuManager.exe` 与 ADB 连接状态，并测试坐标注入是否正常。*

3. **开始运动模拟**：
   ```bash
   # 使用默认配置（ZJGroute.txt 浙大紫金港跑道，目标 2.5 公里）
   python main.py

   # 自定义参数启动（例如目标 3 公里，速度 3.5 m/s）：
   python main.py --distance 3000 --speed 3.5

   # 按圈数跑（例如跑 5 圈）：
   python main.py --laps 5
   ```

## ⚙️ 配置文件说明 (`config.yaml`)

项目核心参数均可在 `config.yaml` 中灵活调整：

```yaml
# 模拟器设置
mumu:
  # 模拟器安装路径。留空 "" 时将完全自动探测
  path: ""
  vm_index: 0          # 多开模拟器索引，单开为 0
  auto_launch: true    # 若模拟器未启动，是否自动调起
  backend: "mumu_manager"

# 跑步与运动仿真配置
run:
  route_file: "ZJGroute.txt"  # 路线文件路径
  coord_type: "gcj02"        # 输入路线坐标系: gcj02 (高德), wgs84 (原始GPS), bd09 (百度)
  speed_mps: 3.2             # 基础速度 (米/秒)。3.2 m/s 约为 11.5 km/h (配速 5'12"/km)
  speed_jitter_pct: 0.10     # 速度自然波动范围 (±10%)
  gps_jitter_meters: 0.8     # GPS 自然飘移扰动 (米)
  slow_down_on_turns: true   # 弯道自动减速
  interval_sec: 1.0          # 定位刷新间隔(秒)

# 运动目标限制
target:
  distance_meters: 2500      # 目标跑步里程(米)。例如 2500 表示 2.5 公里。0 表示不限制
  laps: 0                    # 目标圈数。0 表示不限制
  infinite_loop: false       # 是否无限循环跑（直到按 Q 退出）

# ADB 辅助工具
adb:
  auto_connect: true         # 是否启动时自动建立 ADB 连接
  target_package: "net.crigh.mysport"  # 目标运动应用包名（状态栏监控）
```

## 🗺️ 路线生成与制作（可视化工具）

本项目提供了内置的 **Web 地图可视化路线生成器**，支持高德卫星地图看线、**3 点智能拟合 400m 标准操场跑道** 以及 **自由路径绘制**。

### 1. 启动路线编辑器
- **方式一（一键双击）**：双击运行项目根目录下的 **[`draw_route.bat`](file:///c:/MyTools/playground/runningMIGU/draw_route.bat)**；
- **方式二（菜单启动）**：双击 `start.bat`，在菜单中输入 **`5`** 回车；
- **方式三（命令行）**：执行 `python route_editor.py` 或 `python main.py --editor`。

启动后将自动在默认浏览器中打开交互式地图编辑页面（默认地址 `http://127.0.0.1:8765`）。

---

### 2. 功能模式说明

#### 🎯 模式一：操场跑道智能拟合（推荐，3 点即可生成标准跑道）
利用国际标准 400 米田径跑道几何模型（两条平行直道 + 两个半圆弯道）：
1. 放大地图切换至 **高德卫星影像图**，清晰看见学校操场跑道红道；
2. 依次在跑道上点击 **3 个约束点**：
   - **点 1（直道起点）**：弯道刚结束、进入直道的交界点；
   - **点 2（直道终点）**：直道结束、进入弯道的交界点；
   - **点 3（对向直道点）**：对侧直道的任意位置（用于确定操场跑道宽度和半圆弧半径）；
3. **点击第 3 点后，系统将自动数学计算并拟合出一条光滑闭合的标准操场跑道轨迹**；
4. 顶部实时显示圈长（约 400~450 米）、总点数及闭合状态；
5. 在右侧面板输入文件名（如 `ZJGroute.txt` 或 `my_track.txt`），点击 **【💾 直接保存至项目文件】** 即可！

#### ✏️ 模式二：自由打点模式
- 沿着校园任意林荫道、公路或园区依次点击拐角和路口；
- 点击 **【闭合回路】** 自动连接首尾形成循环；
- 点击 **【曲线平滑插值】** 可将粗糙折线一键插值为自然平滑的人类奔跑曲线。

---

### 3. 已有路线检查与修改
- 在右侧输入框填写已有文件名（如 `ZJGroute.txt`），点击 **【📂 载入当前项目已有路线】**，地图将自动定位并高亮呈现历史轨迹点。

## ❓ 常见问题 (FAQ)

#### Q1: 提示“无法定位 MuMuManager.exe”怎么办？
- 请确认你安装的是网易 **MuMu 模拟器 12**。
- 若安装在非常规目录，可在 `config.yaml` 中设置 `mumu.path: "你的安装路径"`（例如 `"D:\\Games\\MuMu Player 12"`），或者执行带参命令：
  ```bash
  python main.py --mumu-path "D:\Games\MuMu Player 12"
  ```

#### Q2: 运动 App 中看到的轨迹偏移了几百米？
- 这是因为输入的坐标系与配置不一致。国内地图拾取工具通常是 **GCJ-02 (火星坐标)**，请确认 `config.yaml` 中 `coord_type` 设置为 `"gcj02"`。程序会自动计算并修正偏移量。

#### Q3: 是否支持多开模拟器？
- 完全支持。在 MuMu 多开器中查看对应模拟器的序号（例如 1、2 号机），在运行时指定 `--vm-index 1` 即可独立控制对应的模拟器实例。
